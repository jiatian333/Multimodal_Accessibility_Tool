# 🧭 Multimodal Accessibility Framework

This repository contains a full-stack framework for analyzing and visualizing **multimodal spatial accessibility** across Switzerland — with a particular emphasis on the city of Zurich. The system combines a powerful geospatial **backend processing engine** with an intuitive **frontend web application** for isochrone computation and visualization.

Developed as part of an academic project at **ETH Zürich**, this tool facilitates accessibility analysis across multiple transport modes, including walking, cycling, bike rental, e-scooter rental, car sharing, and private car use.

---

## 📦 Repository Structure

| Directory       | Description                                                                      |
|-----------------|----------------------------------------------------------------------------------|
| `backend/`      | Python-based API and processing logic for generating isochrones and routing data |
| `frontend/`     | Web-based visualization tool for exploring static and dynamic isochrones         |
